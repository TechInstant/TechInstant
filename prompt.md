Build a production-quality, modern SaaS/technology company website for a startup called TechInstant.

BRAND POSITIONING

TechInstant is a technology company that builds SaaS products, AI-powered solutions, digital products, and custom software solutions for individuals, startups, businesses, and organizations.

TechInstant is NOT primarily a free-tools website.

The free-tools platform is only one product/service under the TechInstant ecosystem.

Core positioning:

TechInstant
Build Smarter. Grow Faster.

Supporting message:

“We build modern technology, SaaS products and AI-powered solutions that solve real problems and create measurable value.”

The website should feel like a serious technology startup that could eventually serve international customers.

Do NOT make it look like a generic AI-generated website, template, crypto website, or simple portfolio.

---

DESIGN DIRECTION

Create a premium, modern technology/SaaS aesthetic.

Visual characteristics:

- Professional
- Minimal
- Confident
- Innovative
- Human
- Trustworthy
- Enterprise-ready
- Modern but not overly futuristic
- Excellent whitespace
- Strong typography
- Subtle animations
- High-quality dashboard/product mockups
- Rounded cards but avoid excessive “bubble” design
- Subtle gradients
- Soft shadows
- Clean grid system

Primary brand accent:

- TechInstant green
- Deep navy / near-black
- White
- Soft neutral backgrounds

Use green as the recognizable brand accent rather than making every element green.

Avoid excessive neon effects.

Avoid excessive glassmorphism.

Avoid overly rounded “AI startup” cards everywhere.

---

DARK MODE + LIGHT MODE

Implement a complete theme system.

The website MUST support:

1. Light Mode
2. Dark Mode
3. System Preference

Add a theme toggle in the navigation.

Light mode should use:

- White
- Very light gray
- Deep navy text
- TechInstant green accents

Dark mode should use:

- Deep navy/black background
- Slightly lighter dark cards
- White/light gray typography
- TechInstant green accents

The dark mode should feel premium and intentional, NOT simply “invert the colors.”

Persist the user's theme preference using localStorage.

Respect the user's operating-system preference when no preference has been selected.

Ensure every section, card, form, modal, dropdown, footer and dashboard mockup works correctly in both themes.

IMPORTANT BRAND RULES

TechInstant should feel like:

Stripe + modern SaaS startup + technology consultancy

but it MUST NOT copy any existing company's design.

Do not copy FreeAiden.

FreeAiden-style tools are only inspiration for the separate TechInstant Tools product.

TechInstant itself should communicate:

Technology company
→ SaaS products
→ AI solutions
→ Digital solutions
→ Tools
→ Future products

The design should be sophisticated enough that TechInstant could eventually present itself to startups, companies, NGOs, organizations and international clients.

Create reusable components and a scalable architecture so additional TechInstant products and services can be added later without redesigning the whole site.

Build the website as if it were launching publicly today.
